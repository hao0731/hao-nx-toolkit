# Agents guides

## Policies

- [Nx monorepo agent policy](./docs/policies/nx-agent-policy.md)
  - Read this before exploring the workspace, generating projects, changing Nx project configuration, checking project tags, or running Nx tasks.
  - Use it to decide how to query Nx projects, targets, dependencies, generators, and task execution.
- [Nx boundary policy](./docs/policies/nx-boundary-policy.md)
  - Read and follow this when adding or modifying Nx projects, including their tags, responsibilities, dependencies, or cross-project imports.
  - Ensure classification and role tags and dependency boundaries comply with the policy; keep the policy and applicable enforcement configuration aligned when changing the taxonomy or constraints.
