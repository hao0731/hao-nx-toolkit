# 0.3.0 — release notes

Status: Published to npm on **2026-10-23 (Asia/Taipei)**. Both packages have `latest` set to `0.3.0`.

Both `@hao-nx-toolkit/golang` and `@hao-nx-toolkit/project-boundary` share version `0.3.0`.

## Nx compatibility

- Extend the peer range to `^23.2.0 || ^24.0.0` (stable `>=23.2.0 <25.0.0`, excluding prereleases).
- Retain compatibility with Nx 23.2.0, 23.2.1, and 23.3.0; add Nx 24.0.0 to installed-package E2E and CI.
- Upgrade repository Nx packages and the plugins' `@nx/devkit` dependency to 24.0.0. Apply official migrations, including Vitest 5.0.5 and legacy affected selection for this repository.
- Include dependency inputs in inferred boundary targets so Nx 24 task-based affected selection continues checking reverse dependents. Consumers do not need to enable legacy affected selection.

No consumer migration or Nx 24 upgrade is required for existing Nx 23.2.0 consumers. Go generator APIs and boundary configuration remain unchanged.

## Validation

The Nx upgrade passed builds, lint, typechecking, unit tests, formatting, and both installed-package E2E suites on Nx 23.2.0, 23.2.1, 23.3.0, and 24.0.0. The same checks passed again with the 0.3.0 release manifests: both suites passed on all four Nx versions (116 installed-package E2E checks in total). Package inventory inspection and npm publication dry runs passed. Existing non-null assertion lint warnings remain.

Publication uses the inspected `hao-nx-toolkit-golang-0.3.0.tgz` and `hao-nx-toolkit-project-boundary-0.3.0.tgz` artifacts, with checksums recorded in `SHA256SUMS`.

## Publication verification

The registry tarballs are byte-identical to the inspected local artifacts from preparation commit `28a664b`, and both SHA-512 integrity values match. Strict-peer registry consumers passed on Nx 23.2.0 and 24.0.0, including Go model generation and compilation, root boundary initialization, workspace JSON reporting, and inferred project checks.

The commits and annotated `v0.3.0` tag were pushed on **2026-10-23 (Asia/Taipei)**. The [GitHub Release](https://github.com/hao0731/hao-nx-toolkit/releases/tag/v0.3.0) provides both tarballs and `SHA256SUMS` and is marked latest. The tag identifies commit `28258ab`; only release-status documentation differs from artifact preparation commit `28a664b`. Local artifacts remain in `tmp/releases/0.3.0/`.

## Dependency audit limitation

The npm registry smoke installations reported five high-severity findings for the Nx 23.2.0 consumer, and one moderate plus one high-severity finding for the Nx 24.0.0 consumer. These are npm install audit summaries; no audit fix or claim of dependency vulnerability remediation is included in this release.
